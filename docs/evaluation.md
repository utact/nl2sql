# 평가 결과

동일한 뷰와 컬럼 설명을 제공한 SQL 직접 생성 방식과 본 구현을 비교했다. 저장된 측정일은 2026-08-20이며, 모델별로 14문항을 5회씩 실행했다. 14문항은 시맨틱 조회 8개, 추가 확인 3개, 답변 불가 3개로 구성된다.

| 모델 | 직접 생성: 오답 반환 | 본 구현: 오답 반환 | 본 구현: 답변 가능 질문 미제공 |
| --- | ---: | ---: | ---: |
| Qwen2.5 0.5B | 35 | 10 | 35 |
| Qwen2.5 1.5B | 40 | 10 | 35 |
| Llama 3.1 8B | 47 | 0 | 40 |
| gpt-oss 20B | 34 | 1 | 0 |
| gpt-oss 120B | 40 | 2 | 0 |

오답 반환은 기대 결과와 다른 응답이나, 추가 확인·답변 불가가 필요한 질문에 결과를 반환한 경우다. 마지막 열은 답변 가능한 8문항의 40회 실행 중 성공 상태로 응답하지 못한 횟수다. 따라서 Llama 3.1 8B의 오답 0건은 높은 답변 정확도를 뜻하지 않는다.

이 비교에서는 모든 모델의 오답 반환 횟수가 줄었지만, 시맨틱 레이어만의 효과를 분리해 측정한 것은 아니다. 라우팅, 컴파일러, SQL 검사와 답변 보류가 함께 적용됐다. 다음 한계도 있다.

- 단일 합성 데이터와 14문항에 대한 결과다. 모델 크기나 실서비스 전체 정확도에 일반화할 수 없다.
- 기대 결과도 같은 카탈로그와 컴파일러로 만든다. 정의 자체의 업무 적합성을 독립적으로 검증한 평가는 아니다.
- 추가 확인·답변 불가 문항에서는 성공 상태가 아닌 응답을 모두 통과로 집계한다. 적절한 확인 질문과 실행 오류를 구별하는 평가가 추가로 필요하다.
- `free` 경로, 해석 설명의 정확성, 사용자가 설명을 읽고 수정하는 효과는 이 표에서 평가하지 않았다.

원자료는 [로컬 모델 측정](../tests/bench_ladder_huggingface.json)과 [API 모델 측정](../tests/bench_ladder_nvidia.json)에 있다. Llama 3.1 70B는 엔드포인트의 지연·시간 초과로 비교표에서 제외했으며 원자료는 보존했다. 재측정 없이 결과를 확인하려면 다음 명령을 실행한다.

```bash
python tests/bench_ladder.py --report
```
